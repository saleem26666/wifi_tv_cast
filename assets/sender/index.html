Cast laptop → TV

Keep the phone/TV app running on the same WiFi. Use Chrome or Edge.

Chrome blocks screen share on plain HTTP (“Not secure”). Open the https:// address shown in the phone app (port 8443), then click Advanced → Proceed for the certificate warning.

Or in Chrome open chrome://flags/#unsafely-treat-insecure-origin-as-secure, enable it, add this page’s exact URL, relaunch Chrome, and try again.
